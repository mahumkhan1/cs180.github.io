Real API — FastAPI Backend

The full production API runs on FastAPI with API key auth, batch inference, anomaly/drift detection, and structured audit logging. Deploy with Docker or Kubernetes.

# POST /predict
curl -X POST https://your-api/predict \
  -H "X-API-Key: your-key" \
  -H "Content-Type: application/json" \
  -d '{"text": "I love this product!"}'

# Response
{
  "sentiment": "positive",
  "score": 0.94,
  "label": 1,
  "flagged": false,
  "flags": []
}
